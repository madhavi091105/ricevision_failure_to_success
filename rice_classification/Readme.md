# 🌾 RiceVision — Rice Grain Classification

![Python](https://img.shields.io/badge/Python-3.8+-blue)
![PyTorch](https://img.shields.io/badge/PyTorch-2.0+-red)
![License](https://img.shields.io/badge/License-MIT-green)

A deep learning-based rice grain classification system built through systematic experimentation across 150+ runs. The system classifies rice grains into 4 varieties using transfer learning, fine-tuning, and K-Fold cross-validation.

> 🔗 Part of the RiceVision project — see also: [RiceVision-Detection](https://github.com/yourusername/RiceVision-Detection)

## 📌 Overview

| Property | Details |
|---|---|
| Task | Multi-class grain classification |
| Classes | 1401_sella, 1509_sella, 1718_sella, Taaj_sella |
| Dataset Size | 1,600 images (320 train / 80 test) |
| Best Model | EfficientNet-B3 |

| Final Accuracy | XX% |

## 🗂️ Dataset

Dataset was built from scratch and expanded iteratively from 800 to 1,600 images across 4 rice grain varieties.
